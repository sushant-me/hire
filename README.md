# hire

A single page to send instead of an attachment: what I do, the evidence for it, how I
work, and how to start.

Live at **https://sushant-me.github.io/hire/**

It is one self-contained HTML file with no build step and no dependencies, so it also
prints cleanly to PDF for proposals (`chromium --headless --print-to-pdf`).

Every claim on the page names the public source that proves it, and those sources are
re-checked weekly by [sushant-me/reputation](https://github.com/sushant-me/reputation) —
which goes red when one stops holding.
